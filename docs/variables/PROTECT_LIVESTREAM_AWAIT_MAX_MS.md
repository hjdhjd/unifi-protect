# Variable: PROTECT\_LIVESTREAM\_AWAIT\_MAX\_MS

```ts
const PROTECT_LIVESTREAM_AWAIT_MAX_MS: 10000 = 10000;
```

Livestream await window ceiling, in milliseconds - the upper bound of the live-recovery clamp, which [PROTECT\_LIVESTREAM\_AWAIT\_MIN\_MS](PROTECT_LIVESTREAM_AWAIT_MIN_MS.md) describes with its floor.
