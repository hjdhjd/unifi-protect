# Interface: EventsReconnectingPayload

Payload published on [channels.eventsReconnecting](../variables/channels.md#property-eventsreconnecting). `reason` is the fault that dropped the events channel, rendered with its cause chain as
`formatErrorChain` renders it, or a generic description when no fault was recorded.
